# Brineomatic Firmware

This is the firmware that runs on a [Brineomatic](https://github.com/hoeken/brineomatic) compatible board.  

For detailed documentation, please visit the [Brineomatic documentation](https://brineomatic.com/docs/software.html)

The experimental [Victron Cerbo integration scaffold](integrations/victron/README.md)
targets Venus OS 3.81 with a native GUI-v2 plugin and modern Switch-pane indicators.
